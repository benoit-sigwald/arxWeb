Einstein — my self-built research platform

A working example of what "Claude-native" means in practice.

An MCP research server, end to end

Einstein is an MCP server I designed, built and host myself. It gives Claude free web search, page reading, and a persistent archive of sourced research syntheses — stored in a self-hosted PostgREST database with French full-text search. The server contains no LLM: Claude orchestrates, Einstein provides the tools and the memory. Nearly twenty deep-research dossiers are archived and searchable, from trading-strategy literature reviews to public-policy analyses.

Deployed on the OCI server via Coolify — a git push to master is a production deployment.
