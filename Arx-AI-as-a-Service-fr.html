01 — Le récit

Pourquoi, et comment

L'objectif : tout centraliser sur un serveur gratuit, sans renoncer au confort développeur de Vercel ou Render.

1 · Les fondations

Ubuntu 24.04 sur un OCI Ampere A1 (ARM64). Deux couches de pare-feu — Security List OCI + iptables de l'instance — sous-domaines DuckDNS avec mise à jour d'IP par cron.

2 · La plateforme

Coolify en PaaS auto-hébergé : builds depuis GitHub, déploiements en conteneurs Docker, variables d'environnement et cron. Traefik termine le HTTPS avec certificats Let's Encrypt automatiques.

3 · Les charges applicatives

Serveurs MCP, services web et API, chacun dans son conteneur, routés par nom d'hôte et chemin. Environnements de test et de prod, déployés par git push (webhook Coolify).

4 · Les données

PostgreSQL/PostgREST auto-hébergé (même syntaxe d'API que Supabase — zéro changement de code) plus une base Oracle. 500+ lignes migrées avec recherche plein texte intacte ; sauvegardes automatiques vers OCI Object Storage.

02 — Schémas

Schémas d'architecture

L'image complète, du flux de migration à la couche de services.

1 · Vue d'ensemble de la plateforme

L'architecture consolidée : source de vérité GitHub, périmètre de sécurité à deux niveaux, calcul ARM64 OCI Always Free, services FastMCP, couche de données PostgreSQL et intégration IA Souveraine.

2 · Applications OCI et cartographie des services

La topologie complète des microservices : routage TLS Traefik, applications web (CapGrowth, Mailer, Tracker, Linki, Blackstone), cluster FastMCP (Mistral, Einstein, Saul, Omni, Auto) et PostgreSQL 18 avec recherche vectorielle.

3 · Mode Mistral Free & routeur d'IA Souveraine

Le pipeline intelligent de requêtes IA : autorisation FastMCP TokenGuard, suivi de capacité, cache LRU 24h, protection anti-rate-limit et bascule automatique vers le Cloud Souverain OCI Generative AI.

4 · Livraison, synchronisation et reprise après sinistre

La boucle opérationnelle automatisée : livraison vérifiée GitHub, builds automatiques Coolify, monitoring de santé 2 couches, sauvegardes chiffrées quotidiennes et reprise après sinistre testée.

03 — Services plateforme

Les services de la plateforme, un par un

Les briques derrière chaque application déployée : le plan de déploiement, la couche de données, le stockage objet et les sauvegardes.

Coolify — plan de déploiement

Construit depuis GitHub à chaque push, déploie des conteneurs Docker 27 avec bascule à chaud sans coupure (zero-downtime swap), gère variables d'environnement et tâches planifiées — le tout piloté via son API REST.

Couche de données — PostgreSQL 18 + pgvector + PostgREST + Oracle ATP

Une API de données auto-hébergée compatible Supabase avec vectorisation sémantique IA (pgvector) et PostgREST OpenAPI, aux côtés d'Oracle ATP 23ai. Migration sans aucune perte avec introspection instantanée.

MinIO — stockage objet compatible S3

Stockage objet S3 haute performance avec URLs pré-signées pour les fichiers applicatifs, sécurisé derrière Traefik TLS et réseau bridge Docker isolé.

Sauvegardes — automatiques, hors conteneur

Snapshots quotidiens chiffrés (AES-256) à 03h00 UTC expédiés vers OCI Object Storage, avec vérification d'intégrité SHA256 et validation périodique de reprise après sinistre.
