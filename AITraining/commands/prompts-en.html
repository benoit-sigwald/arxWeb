Goodies

99 prompt
shortcuts.

A list that went viral on social media — not Claude Code commands, but keywords to type at the start of any Claude conversation to get a specific format without describing it every time.

What it is — and isn't

A distinction worth knowing before you use them.

A phrasing shortcut

Not an installed feature

Typing /eli10 interest rates is the same as writing "explain interest rates like I'm 10". Claude recognises the keyword and applies the matching format — nothing to install, no file to create.

Unlike: the real Claude Code slash commands, which point to a SKILL.md file run by the harness.
Works anywhere

Chat, Claude Code, API — same principle

These are language conventions, not a technical mechanism: they work as well on claude.ai as through the API, as long as Claude understands the intent behind the keyword.

The real value

Saving time on requests you make often

Useful for the asks you repeat often — rephrasing, deciding, summarising — without retyping the instruction each time. The output still varies run to run: these are shortcuts, not guarantees.

How to use them

In practice

Keyword first, your content after

Example: /negotiate they offered 52k, I'm aiming for 60k, two years' seniority, I have a competing offer. The more precise the context after the command, the better the result — the keyword shapes the format, it doesn't replace the information.

Origin

A community list, not Anthropic documentation

These 98 shortcuts have been circulating as an image on social media (LinkedIn, Instagram, Threads) since early 2026, popularised in part through Hasan Toor's "Claude Secret Codes". They're neither official commands nor Claude Code commands: treat this as a cheat sheet of useful phrasings, not a product reference.

One entry in the "Think & decide" category was illegible in the source image — the list above holds 98 verified commands out of the 99 advertised.
