de prompt.

Une liste devenue virale sur les réseaux — pas des commandes Claude Code, mais des mots-clés à taper en début de message dans n'importe quelle conversation Claude pour obtenir un format précis sans le décrire à chaque fois.

Ce que c'est — et ce que ce n'est pas

Une nuance qui compte avant de les utiliser.

Un raccourci de formulation

Pas une fonctionnalité installée

Taper /ELI10 les taux d'intérêt revient à écrire « explique-moi les taux d'intérêt comme si j'avais 10 ans ». Claude reconnaît le mot-clé et applique le format associé — il n'y a rien à installer, aucun fichier à créer.

À la différence de : les vraies commandes slash Claude Code, qui pointent vers un fichier SKILL.md exécuté par le harness.
Marche partout

Chat, Claude Code, API — même principe

Ce sont des conventions de langage, pas un mécanisme technique : elles fonctionnent aussi bien sur claude.ai qu'en API, tant que Claude comprend l'intention derrière le mot-clé.

L'intérêt réel

Gagner du temps sur les formulations répétitives

Utile pour les demandes qu'on refait souvent — reformuler, trancher, résumer — sans retaper la consigne à chaque fois. Le résultat reste variable d'une fois sur l'autre : ce sont des raccourcis, pas des garanties.

Comment s'en servir

En pratique

Le mot-clé au début, votre contenu ensuite

Exemple : /negotiate on me propose 52k, je vise 60k, deux ans d'ancienneté, j'ai une contre-offre en main. Plus le contexte fourni après la commande est précis, meilleur est le résultat — le mot-clé cadre le format, il ne remplace pas l'information.

Origine

Une liste communautaire, pas une doc Anthropic

Ces 98 raccourcis circulent sous forme d'image sur les réseaux sociaux (LinkedIn, Instagram, Threads) depuis début 2026, popularisés notamment via les « Claude Secret Codes » de Hasan Toor. Ce ne sont ni des commandes officielles ni des commandes Claude Code : traitez-les comme un pense-bête de formulations utiles, pas comme une référence produit.

Un intitulé de la catégorie « Réfléchir & décider » restait illisible sur l'image source — la liste ci-dessus compte 98 commandes vérifiées sur les 99 annoncées.
